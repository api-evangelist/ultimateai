# Ultimate.ai

> Ultimate.ai was a Helsinki- and Berlin-based customer support automation platform (virtual agents / chatbots with intent recognition), backed by HV Capital and Techstars. It was acquired by Zendesk in 2024; the product now ships as Zendesk AI agents (the "AI agents - Advanced" add-on) and ultimate.ai redirects to zendesk.com. The legacy Ultimate.ai Public API on chat.ultimate.ai is retired (probed endpoints return 404); its Slate docs source survives in the ultimateai GitHub org.

## APIs

- [Zendesk AI Agents API (formerly Ultimate.ai)](https://developer.zendesk.com/api-reference/ai-agents/introduction/): Successor API surface - Chat, Ticket, Widget Escalation APIs + webhooks, Data Export, Delete User Data. Base URL https://{subdomain}.zendesk.com/ai-agents/api; API keys are still generated from the Ultimate.ai dashboard (Custom CRM integration page).
- [Ultimate.ai Public API (legacy, retired)](https://github.com/ultimateai/public-api): Chat Automation (POST /api/v2/automation), Intent Recognition (POST /api/intents), Delete User Data (POST /api/gdpr/delete-user-data) on https://chat.ultimate.ai with Basic auth / bot access tokens.
